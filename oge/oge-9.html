Уравнения

📖 Теория (шпаргалка)

  • Линейные уравнения: переносим слагаемые с \(x\) влево, числа вправо. \(ax = b \Rightarrow x = b/a\).
  • Квадратные уравнения: \(ax^2 + bx + c = 0\). Дискриминант \(D = b^2 - 4ac\). Если \(D > 0\), два корня: \(x = \frac{-b \pm \sqrt{D}}{2a}\).
  • Дробные уравнения: находим общий знаменатель, умножаем обе части, не забываем про ОДЗ (знаменатель не равен нулю).

✍️ Примеры из ФИПИ

    Ответ: \(1; 0,5\)
  2. Решите уравнение: \(\frac{x}{3} + \frac{x}{4} = 7\)
