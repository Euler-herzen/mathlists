Парадокс дней рождения

В классе учится N человек. Какова вероятность того, что хотя бы у двух из них день рождения совпадает (число и месяц)?

На первый взгляд кажется, что для этого нужно очень много людей. Но математика говорит об обратном.


Ваша задача: Выведите формулу и найдите вероятность для 30 человек с точностью до десятитысячных долей процента.

💡 Подсказка

Считать вероятность того, что дни рождения совпадут, сложно. Проще найти вероятность противоположного события: того, что у всех людей дни рождения разные. А затем вычесть её из единицы: \(P(совпадение) = 1 - P(все разные)\).

✅ Решение и формула

Теория: Будем считать, что в году 365 дней (високосные года игнорируем для простоты).

Первый человек может родиться в любой из 365 дней. Второй — в любой из оставшихся 364 дней (чтобы не совпасть с первым). Третий — в любой из 363 дней и т.д.

Вероятность того, что у N человек дни рождения разные:

\(P_{разные} = \frac{365}{365} \cdot \frac{364}{365} \cdot \frac{363}{365} \cdots \frac{365 - N + 1}{365}\)

Тогда искомая вероятность совпадения:

\(P_{совпадение} = 1 - P_{разные}\)

Пример кода на Python:

def birthday_probability(n):
    if n > 365: return 1.0
    p_no_match = 1.0
    for i in range(n):
        p_no_match *= (365 - i) / 365
    return 1 - p_no_match

# Вывод с точностью до 4 знаков после запятой
for n in [10, 20, 30, 50, 70]:
    print(f"{n} человек: {birthday_probability(n)*100:.4f}%")
