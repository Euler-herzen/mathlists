Проверочная работа — Кусочно-заданные функции (10–15 минут)

Вариант 1

1. Функция задана формулой:
\( y = \begin{cases} 2x, & \text{если } x \le 1, \\ x + 3, & \text{если } x > 1. \end{cases} \)
Найдите \( y \) при \( x = 0 \).
x = 0 ≤ 1, значит y = 2·0 = 0
2. Для той же функции найдите \( y \) при \( x = 3 \).
x = 3 > 1, значит y = 3 + 3 = 6
3. Постройте график функции:
\( y = \begin{cases} -x, & \text{если } x < 0, \\ x, & \text{если } x \ge 0. \end{cases} \)
Опишите, из каких частей он состоит.
График состоит из двух лучей: при x < 0 — луч y = −x (убывает), при x ≥ 0 — луч y = x (возрастает). Вместе образуют «уголок» с вершиной в (0; 0).
4. Функция задана формулой:
\( y = \begin{cases} x^2, & \text{если } -2 \le x \le 2, \\ 4, & \text{если } x > 2. \end{cases} \)
Найдите \( y \) при \( x = -1 \) и при \( x = 5 \).
При x = −1: y = (−1)² = 1; при x = 5: y = 4
5. При каком значении \( x \) функция из задания 1 принимает значение \( y = 5 \)?
Если x ≤ 1: 2x = 5 → x = 2,5 — не подходит (2,5 > 1). Если x > 1: x + 3 = 5 → x = 2 — подходит. Ответ: x = 2.

Вариант 2

1. Функция задана формулой:
\( y = \begin{cases} 3x, & \text{если } x \le 2, \\ x - 1, & \text{если } x > 2. \end{cases} \)
Найдите \( y \) при \( x = 1 \).
x = 1 ≤ 2, значит y = 3·1 = 3
2. Для той же функции найдите \( y \) при \( x = 4 \).
x = 4 > 2, значит y = 4 − 1 = 3
3. Постройте график функции:
\( y = \begin{cases} 2x, & \text{если } x < 1, \\ -x + 3, & \text{если } x \ge 1. \end{cases} \)
Опишите, из каких частей он состоит.
График состоит из двух частей: при x < 1 — луч y = 2x (возрастает), при x ≥ 1 — луч y = −x + 3 (убывает). В точке x = 1 значения не совпадают (y = 2 при x < 1 стремится к 2, а при x ≥ 1 y = 2) — график непрерывен в этой точке.
4. Функция задана формулой:
\( y = \begin{cases} -x, & \text{если } -3 \le x \le 0, \\ x^2, & \text{если } x > 0. \end{cases} \)
Найдите \( y \) при \( x = -2 \) и при \( x = 3 \).
При x = −2: y = −(−2) = 2; при x = 3: y = 3² = 9
5. При каком значении \( x \) функция из задания 1 принимает значение \( y = 6 \)?
Если x ≤ 2: 3x = 6 → x = 2 — подходит. Если x > 2: x − 1 = 6 → x = 7 — подходит. Ответ: x = 2 или x = 7.
