Проверочная работа — Кусочно-заданные функции ★

1 ★. Функция задана формулой:
\( y = \begin{cases} -x + 2, & \text{если } x < 1, \\ x^2, & \text{если } x \ge 1. \end{cases} \)
При каких значениях \( x \) значение функции равно \( 4 \)?
Если x < 1: −x + 2 = 4 → x = −2 — подходит (−2 < 1). Если x ≥ 1: x² = 4 → x = 2 (x = −2 не подходит, т.к. −2 < 1). Ответ: x = −2 или x = 2.
2 ★. Постройте график функции:
\( y = \begin{cases} x + 1, & \text{если } x \le 0, \\ -x + 1, & \text{если } x > 0. \end{cases} \)
Определите, при каких значениях \( m \) прямая \( y = m \) пересекает график ровно в двух точках.
График — «уголок» с вершиной в (0; 1), ветви вниз. Прямая y = m пересекает его в двух точках при m < 1 (включая все m < 1; при m = 1 — одна точка). Ответ: m < 1.
3 ★. Функция задана формулой:
\( y = \begin{cases} 2x - 1, & \text{если } -1 \le x \le 2, \\ 5, & \text{если } x > 2. \end{cases} \)
Найдите область значений функции.
При −1 ≤ x ≤ 2: y = 2x − 1, значения от −3 до 3. При x > 2: y = 5. Область значений: [−3; 3] ∪ {5}.
4 ★. Задайте аналитически (одной или несколькими формулами) функцию, график которой состоит из двух лучей: \( y = 3x \) при \( x < 0 \) и \( y = -x + 4 \) при \( x \ge 0 \).
y = 3x при x < 0; y = −x + 4 при x ≥ 0. Это кусочно-заданная функция.
5 ★. При каком значении \( a \) график функции
\( y = \begin{cases} ax, & \text{если } x < 2, \\ x + 1, & \text{если } x \ge 2 \end{cases} \)
проходит через точку \( (2; 3) \)?
При x = 2 выполняется вторая ветвь: y = 2 + 1 = 3 — точка (2; 3) уже лежит на графике при любом a. Значит, a — любое число (но по смыслу задачи коэффициент a в первой ветви не влияет на точку x = 2). Ответ: a — любое.
