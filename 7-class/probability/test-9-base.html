1. Дан набор чисел: \(9, 4, 12, 7, 15, 4\).
а) Наименьшее значение:
б) Наибольшее значение:
в) Размах:
а) 4; б) 15; в) \(15 - 4 = 11\).
2. Размах числового набора равен \(14\). Наибольшее значение равно \(20\). Чему равно наименьшее значение?
\(20 - 14 = 6\).
3. Количество прочитанных страниц книги за пять дней: \(12, 18, 10, 22, 15\). Найдите размах.
\(22 - 10 = 12\).
4. В ряду чисел \(3, 7, x, 12\) наименьшее значение равно \(3\), а размах равен \(11\). Найдите \(x\).
Наибольшее \(3 + 11 = 14\), значит \(x = 14\).
5. Как изменится размах числового набора, если каждое число набора увеличить на \(5\)? Ответ обоснуйте.
Размах не изменится, так как наибольшее и наименьшее значения увеличатся на 5, а их разность останется прежней.
