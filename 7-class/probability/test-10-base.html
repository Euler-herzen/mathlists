Вариант 1
1. Дан набор чисел: \(4, 8, 6, 2, 10\). Найдите \(\min X\) и \(\max X\).
\(\min X =\) \(\max X =\)
\(\min X = 2, \max X = 10\).
2. Среднее арифметическое набора \(X\) равно \(15\). Каждое число набора уменьшили на \(6\). Чему равно среднее арифметическое нового набора?
\(15 - 6 = 9\).
3. Среднее арифметическое набора из \(5\) чисел равно \(4\). Каждое число набора умножили на \(5\), а затем прибавили \(2\). Найдите среднее арифметическое нового набора.
\(4 \cdot 5 + 2 = 22\).
4. В наборе из \(4\) чисел среднее арифметическое равно \(10\). К набору добавили число \(20\). Найдите среднее арифметическое нового набора из \(5\) чисел.
Сумма 4 чисел: \(40\). Новая сумма: \(60\). Среднее: \(60 : 5 = 12\).
5. Среднее арифметическое набора из \(10\) чисел равно \(8\). Из набора удалили число \(15\). Найдите среднее арифметическое оставшихся \(9\) чисел.
Сумма была \(80\). Осталось \(65\). Среднее: \(65 : 9 = 7\frac{2}{9}\) (или \(\approx 7,22\)).
Вариант 2
1. Дан набор чисел: \(9, 3, 7, 5, 1\). Найдите \(\min X\) и \(\max X\).
\(\min X =\) \(\max X =\)
\(\min X = 1, \max X = 9\).
2. Среднее арифметическое набора \(X\) равно \(12\). Каждое число набора увеличили на \(8\). Чему равно среднее арифметическое нового набора?
\(12 + 8 = 20\).
3. Среднее арифметическое набора из \(6\) чисел равно \(5\). Каждое число набора умножили на \(4\), а затем вычли \(3\). Найдите среднее арифметическое нового набора.
\(5 \cdot 4 - 3 = 17\).
4. В наборе из \(5\) чисел среднее арифметическое равно \(12\). К набору добавили число \(24\). Найдите среднее арифметическое нового набора из \(6\) чисел.
Сумма 5 чисел: \(60\). Новая сумма: \(84\). Среднее: \(84 : 6 = 14\).
5. Среднее арифметическое набора из \(8\) чисел равно \(10\). Из набора удалили число \(17\). Найдите среднее арифметическое оставшихся \(7\) чисел.
Сумма была \(80\). Осталось \(63\). Среднее: \(63 : 7 = 9\).
